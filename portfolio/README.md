# Портфолио Полины Павловой

Статичный одностраничник, без бэкенда. Открывается прямо как файл, но для
корректной работы динамической подсветки фона (она использует Canvas API)
лучше смотреть через локальный сервер или сразу на GitHub Pages — при
открытии `index.html` напрямую двойным кликом (`file://`) подсветка может
не включаться в Chrome из-за ограничений браузера на чтение пикселей с
локальных файлов. Всё остальное (анимации, лайтбокс, сетка) работает и так.

## Структура

```
index.html      — разметка и весь текст
styles.css      — стили, токены дизайна
script.js       — анимации на скролл, подсветка фона, лайтбокс
images/         — все работы + текстура грейна
```

## Как выложить на GitHub Pages (бесплатно)

1. Создай новый репозиторий на GitHub (например, `polina-portfolio`).
2. Загрузи туда все файлы из этой папки, сохранив структуру (`index.html`
   должен лежать в корне репозитория).
3. В репозитории: **Settings → Pages → Build and deployment → Source** —
   выбери `Deploy from a branch`, ветку `main`, папку `/ (root)`.
4. Через минуту-две сайт появится по адресу
   `https://<твой-логин>.github.io/polina-portfolio/`.

Если захочешь подключить свой домен — это делается там же, в Pages →
Custom domain.

## Как поменять/добавить работу

Каждая работа — это один блок `<figure class="tile ...">` в `index.html`.
Чтобы заменить картинку — положи новый файл в `images/` и поменяй `src`
(и `data-src`) на новое имя файла. Число в классе `span-N` определяет
ширину плитки в сетке из 12 колонок — крупнее число, крупнее плитка.

## Локальный просмотр

```
python3 -m http.server 8000
```

и открыть `http://localhost:8000` в браузере.
